# 税制マスタの更新管理

所得年2025年と2026年の内蔵版に対応します。住民税課税年度は順に2026年度と2027年度です。現行のカタログでは両年とも `APPROVED` ですが、製品全体の正式受入は保留です。2026年分の通常の年末調整を想定し、施行日前の準確定申告等は対象外とします。

## v4のカタログと適用範囲

書式は `所得年|承認状態|版番号|URL|SHA-256` です。更新処理はGitHubのmainからカタログを取得し、対象年の行が1件だけ存在し、承認状態と内蔵版番号が一致するときに内蔵マスタを適用します。更新前に入力を含むブックを保存し、内蔵テストとマスタチェックを通過してから更新を保存します。

外部XLSXの取込は保留中です。従来版はリモートブックの数式を回帰テストとして取り込んでおり、テストの独立性を保証できませんでした。将来年度は一次資料によるレビュー、数式を含まないデータ形式、版互換性・完全性の検証、および独立期待値と障害試験の確立後に開放します。2027年分は未承認です。
