# Furusato_nouzei — ふるさと納税限度額計算

2025年・2026年分の源泉徴収票を基に住民税所得割とふるさと納税の寄附上限の**目安**を計算するExcelブックです。2027年分は未承認（fail closed）。

## 使い方

1. **ZIPを「すべて展開」**します。ZIP直下に `ふるさと納税限度額計算_修正版.xlsx`、`初回セットアップ.cmd`、`初回セットアップ.ps1`、`TaxLawUpdater.bas` が揃っていることを確認します。ZIPはUTF-8ファイル名で作成し、階層を作りません。
2. Windows / Excel 365で **`初回セットアップ.cmd` をダブルクリック**すると、同じフォルダにマクロ付きブック（`.xlsm`）ができます。`.ps1`は内部処理用で通常は直接起動しません。
3. 以降は **操作画面 → 適用年を選択 →「税制を更新」** で更新します。
4. 源泉徴収票を入力し、必要な場合だけ扶養・生命保険・追加人的控除を入力します。
5. 「整合性チェック」の判定を確認します。

## 改正対応の仕組み

- リポジトリの [taxdata/catalog.tsv](taxdata/catalog.tsv) に**承認済（APPROVED）**の年分だけを登録します。
- 2025年分・2026年分は納品ブック内の監査済マスタを利用します。
- 新しい年度や過年度改正は、9種類の税制マスタと独立した期待値テストを含むXLSXパックをGitHub Releasesに公開し、SHA-256とリンクをカタログに登録します。
- Excelの更新機能はGitHub公開カタログを確認し、未承認年度・SHA不一致・テスト不合格では更新しません。
- 現時点では2027年分の更新パックは未提供です。ボタンを押しても未承認年は適用しません。
- **税法をネットから自動解釈するものではありません。** 専門家が検証・承認したデータをワンクリックで取り込む設計です。

## 数値の取扱い

- 所得年と翌年の住民税課税年度は別です。
- 特例控除の基準は原則として調整控除後の所得割額を使用します。
- 寄附上限額は一般的な給与所得者向けの試算で、住宅ローン控除・分離課税・他の税額控除・寄附金総額などは個別確認が必要です。
- 未入力・未承認年・例外条件では確定した金額を提示しません。
- 既存のExcel .xlsm マクロは承継していません。今回のVBAは初回セットアップで新たに導入します。

## 検証

- 年度別の控除マスタ9表、独立回帰テスト52件、式のエラー検索、ユーザー画面の視覚的点検を実施。
- Windows実機上のマクロインポート・ボタン押下テストは**未実施**です。導入後に実機で検証してください。
- 最新の配布ファイルと品質報告はチャットの納品ZIPに含まれています。
