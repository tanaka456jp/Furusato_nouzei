# 源泉徴収票専用・端末内OCRの品質受入基準（2026-11-09）

## 対象と守るべき条件

目的は、HousingERPの**帳票完全性・OCR数値整合性・異常時の登録禁止**と、TaxTheoryAudioAppの**Apple Vision・画像補正・領域再認識の思想**を公開Webへ応用すること。元プロジェクトのコード・保護された個人データを公開リポジトリへ転載しない。HousingERPで利用する有料のGoogle Cloud Document AIと、TaxTheoryAudioAppのiOS専用Apple Visionは**ブラウザで直接利用できる同一OCRエンジンではない**ため、両者の過去の結果をWeb版の品質実証に流用しない。

現在のコードは `Tesseract.js 7.0.0 + jpn 1.0.0 + PDF.js 6.3.289` を公開サイト内に同梱する。入力された画像・PDFは端末外送信せず、原票をサーバーやlocalStorageへ保存しない。ライブラリ/モデルは同一ホストから取得する。CSPは原則外部通信を禁止し、`connect-src 'self'` は同梱資産の配信に限定する。

## 機械的な手順と限界

1. 電子PDFの文字情報をブラウザ内で直接抽出する。複数ページはHOLD。文字不足の場合は同一端末上でPDFを画像化してOCRへ。
2. JPEG・PNGまたは画像化したPDFはCanvasで解像度を制限し、原画像と輝度/コントラスト補正画像を作る。
3. Tesseract.js（同じOCRエンジン）の**原画像と補正画像を2回認識**する。読取信頼度はいずれも75以上、年分・4項目が完全一致した場合だけ候補を表示する。**同一OCRエンジンの2回認識には相関誤りがあるため、独立したAI OCR2機比較の代わりとはみなさない。**
4. 源泉徴収票のタイトル、令和7/8年分（2025/2026）、支払金額、給与所得控除後の金額、所得控除の額の合計額、社会保険料等の金額を確認する。文字列の推測補正・金額の自動穴埋め・複数候補の都合のよい選択は禁止。
5. ページ/年分/金額の不明・不一致・重複・OCR低信頼度ではHOLD。候補が一致した場合も `REQUIRES_SOURCE_REVIEW` を維持。**本人が原票と追加控除・扶養の有無を視認して明示確認するまで入力欄へ転記しない**。
6. 転記後も独立した税額エンジンの源泉徴収票参照値・年分・法定所得控除・所得税/住民税等の照合を通し、未対応条件で寄附限度額は表示しない。

未実装：Webでの台形/遠近補正、項目別座標認識・再撮影ガイド、HEICの安全な変換、Safariの実端末確認。これらはTaxTheoryAudioAppの画像品質判定とHousingERPの原票差分監査を参考に、別途検証して実装する。文章全体が一致するだけでは金額項目の正しさを保証しない。

## AI OCR比較のベンチマーク（まだ未測定）

**同じ原票の正解データ**に対し、電子PDF・複合機スキャン・スマホ画像・低照度・回転/傾き・数字が近接する様式・令和7/8年分を層別評価する。

| 指標 | 定義 | 受入案 |
|---|---|---|
| 重要4項目の完全一致率 | 正解と完全一致した件数／正解欄の総数。HOLDも成功には数えない | 99.5%以上を目標 |
| 1帳票全項目一致率 | 年分＋4項目が全部正解の帳票数／帳票総数 | 99.5%以上を目標 |
| 誤った候補が転記可能になる件数 | 間違った欄値に対し `eligibleForManualTransfer=true` となった件数 | **0件**を必須条件とする（観測0件でも母集団への保証ではない） |
| HOLD率 | 誤判定を含むすべての中止件数／原票総数 | 別途明示（安全性だけでなく操作性も評価） |
| 認識時間・メモリ | PC・iPhone、端末内だけで計測 | 実測後に閾値を決定 |
| 外部送信 | 原票・全文・金額のネットワーク送信 | **0件**（同梱コード・学習データのGETは除く） |

判定時は、原票形式別の標本数、信頼区間、失敗の内訳、機種/OS/ブラウザ、Tesseract/PDF.js版、事前処理版を記録する。低件数の100%と大規模での99.5%を混同しない。商用AI OCRと比較する際は**同じ原票・同じ真値・同じ項目単位**で計測する。

## 現在までの証拠をどう扱うか

- `test-ocr-review.cjs` / `test-ocr-dom.cjs`：**合成文書**を使い、内容誤認・年分違い・重複・不正数値・原票確認不足・控除のHOLDを試験。実精度を示さない。
- `test-ocr-browser-smoke.cjs`：ヘッドレスChromiumで、同一サイトの日本語WASM・学習データを読込み、**人工Canvas**で実際にOCRを起動。読み取り精度を示さない。
- 実Windows Edge・物理iPhone Safariでの実原票/印刷結果・ユーザー視覚品質の検証、およびAI OCRとの同条件比較は **未実施**。
- 旧非公開GASのOCR受入記録は、公開Web版のTesseract OCRとエンジン・権限・保存先が異なるため、流用不可。

個人情報を含む実原票は**公開GitHub、Actions、Artifacts、公開OCRサービスへ送信しない**。所有者が明示的に許可した、端末内での読み取り専用の監査でのみ評価し、原票や全文のログ化・公開は禁止する。

**現在の判定：OCRの構造と安全停止は試験実装済み／真の認識精度、商用品質、一般公開はHOLD。**
