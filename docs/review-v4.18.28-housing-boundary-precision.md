# v4.18.28 — 2022年入居住宅ローン控除の上限到達前後の精度検証

Draft PR #5のレビュー専用。正式リリースはHOLD。

2025年・2026年の所得税基礎控除差の扱いと、住民税住宅ローン控除
上限を合成データのPC①実Excelで照合する。

- 2025年：所得税基礎控除580,000円、総合課税所得加算1,649,000円／1,650,000円
- 2026年：所得税基礎控除620,000円、総合課税所得加算1,609,000円／1,610,000円
- 住民税住宅ローン控除の基礎とする課税所得（基礎控除差加算後）：
  1,949,000円／1,950,000円
- 2022年入居通常5%：97,450円／97,500円
- 2022年入居経過措置7%：136,430円／136,500円
- Excel入力候補のドロップダウンをペーストで回避した不正な確認文字列：
  SAFE-TAX-028で計算見込額が空欄になること

税制判定は引き続き入力元の契約日・取得条件・消費税率等の実資料
確認を前提とし、本ソフトが7%適用資格を自動認定するものではない。
実案件や既存正式版・本番GASに書き込まない。
