# Excel v4.18.26：電子PDFの文字衝突検査を実CIへ追加

正式リリース：HOLD。Draft PR #5でのみ検証。

## 検出対象と実装

電子PDFがA4内に存在するだけでは、印刷した文字同士が重なって
読めなくなる不具合を検出できない。この版はWindows実Excelが生成した
合成データPDF5ページを対象に、可視テキスト単語の座標をPyMuPDFで
取り出し、別単語間の有意な**縦・横双方の重なり**を検査する。

- 通常根拠1ページ、非表示からの根拠1ページ、分離課税2ページ、
  操作画面1ページをすべて検査。
- 単独記号や文字の通常カーニングを誤検出しにくい閾値を適用。
- 検査器が意図的に重複させた合成英字を検出する自己試験と、
  重なりのない合成英字を許容する自己試験を毎回実行。
- 衝突・自己試験不合格ならCIをFAILにし、VBAUpdater後続受入を停止。
- JSON証跡にページ別単語数と自己検査結果を記録。
- 元XLSMと既存案件は変更しない。税額数値、既存のA4ページ数、
  版・所得年の見出し、PDF→PNG証跡も従来どおり必須。

## 留保

PDFの文字領域が衝突しないことは、フォントの意匠・余白・物理印刷、
Windows実画面倍率の受入を意味しない。またGAS側の独立再受入、
特殊な税額控除の実額突合は未完了のままHOLDとする。
