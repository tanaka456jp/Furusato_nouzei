# v4.18.33 — Windows表示倍率の独立証跡収集（検証版）

## 目的
これまで「PDFからレンダリングしたPNG」と「Windows Excelの実デスクトップ画面」の
検査が混同される余地があった。表示倍率別の実画面は物理画面および
ユーザー操作を伴うため、すでに成功したPDF試験の結果を流用しない。

## 変更
- PC①の専用self-hosted runnerにて、生成済みの**合成テストXLSMだけ**を
  新たな隔離Excel COMインスタンスで読み取り専用として開く。
- Windowsの解像度として報告される幅・高さと、Excelウィンドウの
  `GetDpiForWindow`（DPI、倍率の推定値）をJSONに記録する。
- 該当Excelウィンドウに限定して `PrintWindow` を実行し、
  タイトルバー・リボンを除外した**シート部分のみ**の画像を採取する。
  Windowsのデスクトップ全体や他の業務アプリの画面は取得しない。
- 画面がない、レンダリングできない、無地画面等の場合は
  `UNVERIFIED` と記録する。証跡取得可能でも
  `CAPTURED_REQUIRES_VISUAL_REVIEW` であり自動で合格にはしない。
- 元Excel、ほかのExcelプロセス、Windows全体の表示倍率と解像度は変更しない。
- `test_display_contract.py` とWindows PowerShell 5.1構文監査を追加し、
  別アプリの画面取得・OS解像度変更・実表示条件の自動合格宣言を拒否する。
- ブック・インストーラーの版表示をv4.18.33に統一。税法・税額の数式は変更なし。

## 受入条件と制限
- 対象の3条件：1920×1080/100%、1920×1080/125%、
  1366×768/150%。**現在のrunnerで観測できた条件だけ**を証跡に記録し、
  残りの条件を合格と推定しない。
- OS/COMのDPI仮想化により、取得した表示幅が物理解像度と異なる場合がある。
  JSONの観測値はハードウェア実測値や目視完了の証明ではない。
- 印刷/画面の視認性、ボタンを押した際の実動作、重なり、実印刷は
  画像の確認を経て別判定する。画像がない場合は引き続きHOLD。
- ユーザーの実データはGitHubやCIに取り込まない。
- GASの実Webアプリ受入、匿名化した実税務資料での独立突合、
  署名済み正式配布は継続HOLD。main・既存正式版・本番GAS不変更。
