# v4.18.21 税額控除安全停止の検証（Draft / HOLD）

## 変更の目的

通常の源泉徴収票計算で、**分離課税詳細用の税額控除入力 D72:D77** が
残っていても通常計算結果には反映されず、目安額だけが表示される危険を防ぐ。
住宅ローン控除の所得税適用額 B33 が正数で、控除可能額（G36）B34 が未入力
または適用額未満の場合も同様に安全停止する。

## 安全判定

- SAFE-TAX-026: 「給与・通常」モードで D72:D77 のいずれかがゼロでない場合
  （住宅の入居年・残高・可能額、配当、外国税額、国外所得を含む）。
  金額の文字入力も黙って無視しない。寄附目安と住民税目安は非表示。
- SAFE-TAX-027: 住宅ローン控除の所得税適用額が正数、B34 が欠落・ゼロ・
  適用額より小さい場合。控除可能額を原票と照合するまで非表示。
- 複雑な税額控除を**計算可能と見せかける変更はしない**。分離課税の
  既存検証済み経路、通常の住宅ローン控除額、2025/2026年の税額マスタ、
  既存正式配布版 v4.18.2 と GAS PR #2 は変更しない。

## 受入検証

- 静的: 6欄すべての通常モード遮断条件、B33/B34の整合性チェック、
  B8/D8の表示ガード、バージョン整合性。
- Windows Excel: 6欄を個別に合成入力→SAFE-TAX-026・結果非表示、
  各リセット後に正常復帰。B33正数/B34欠落またはゼロの2条件→
  SAFE-TAX-027・結果非表示、修復後に正常復帰。
- 既存52ケース、70ケース分離課税、税制更新、VBAUpdater、PDF・保存等の回帰を維持。
  実行証跡がないものをPASSと判定しない。
