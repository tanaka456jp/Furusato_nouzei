# 2025・2026年分の公的税制表との照合

令和7・8年分の税額試算ブックに格納した数値マスタを、国税庁の公表資料で照合する。
算定結果の本人確認、各自治体の端数処理、他の控除との競合を保証するものではない。

- 所得税の基礎控除：国税庁 No.1199
  https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1199.htm
- 給与所得控除：国税庁 No.1410
  https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1410.htm
- 所得税率：国税庁 No.2260
  https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm

`python tools/audit_statutory_tables.py workbook/baseline.xlsx` および
再生成済みブックを指定して、2025/2026の基本控除各9区分、
給与所得控除各5区分、所得税率各7区分を照合する（合計42区分）。
基礎控除の住民税欄は国税庁資料ではなく、従前からの
住民税計算マスタの保持を確認するための内部基準値である。

給与所得控除は、690千円～2,200千円付近の特例・所得金額表、
令和8年12月以降の改正施行日等、条件により別の取扱いがある。
本ソフトは源泉徴収票の「給与所得控除後の金額」を原則入力する。
本チェックは **法令マスタの表値・境界値の差分監視** が目的であり、
実際の給与所得金額の算定を一律の一次式で正確に再現する保証ではない。

参照日：2026年11月6日。実税務資料との多数例照合、現物印刷、
自治体固有税率や例外ケースの網羅は正式受入までHOLD。
