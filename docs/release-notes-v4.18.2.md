# Furusato_nouzei v4.18.2 — 正式配布版

ふるさと納税の寄附限度額を試算するWindows Excel 365向けのマクロ付きブックです。対応する所得年は**2025年・2026年**です。**2027年分は未承認のため計算を停止します。**

## 配布ファイル

- **Furusato_nouzei_v4.18.2_ReadyToUse.zip**：受入済みの `Furusato_nouzei.xlsm` と `FurusatoDocumentReader.exe`、ユーザーガイドを同梱。展開して `Furusato_nouzei.xlsm` を開く方式。**通常はこちらを推奨**します。
- **Furusato_nouzei_v4.18.2_Windows.zip**：Excelでマクロ付きブックを新規生成する初回セットアップ方式（`START_SETUP.cmd`、`setup.ps1`、元のXLSX、VBAソース、源泉徴収票読取EXE、ユーザーガイド）。
- **SHA256SUMS.txt**：配布ファイルの改ざん・転送破損検査に利用するSHA-256一覧。

両ZIPは**別の新しいフォルダに展開**してください。ReadyToUse版では初回セットアップは不要です。Windows版の `START_SETUP.cmd` は同名 `.xlsm` がある場合、上書きしません。

## 計算・操作の範囲

- 2025・2026年分の承認済み内蔵マスタのみ適用（法令マスタ `2026-11-05-bundled`）。
- 給与所得、該当条件下での公的年金・事業・不動産・雑所得、限定された分離課税ケース、一定の住宅ローン控除に対応。
- 所得税・住民税を用いた寄附限度額の試算、計算根拠の表示、Excel印刷プレビュー、PDF保存、案件のコピー保存、税制適用年切替。
- 源泉徴収票の**文字情報を含むPDF**のローカル読取と、原票未確認時の安全停止。

## 試験の証拠・対応範囲の限界

開発元の**合成データ**に基づく自動テスト（ブック内蔵52ケース、Windows Excelの実起動・更新・再計算・案件保存・PDF生成・VBAUpdater隔離書戻し）を受入ゲートとしました。正式配布ワークフローでは同じソースから再構築した配布物とExcel実機受入を照合して公開します。

**以下は実機・実額での全件検証済みではありません：**

- 源泉徴収票と翌年の住民税決定通知書を組み合わせた多数の実案件との完全突合。
- 画像PDF・写真の日本語OCR（必要なTesseract本体と日本語言語辞書は未同梱）。
- 1366×768・150%等の全画面倍率での有人確認、全プリンタでの実印刷。
- 自治体独自の課税、制度の特殊例、未対応所得控除・分離課税・住宅ローン控除の併用、2027年以降の税制。
- デジタルコード署名（**本製品は署名なし**）。

適用範囲外・原票不整合は自動的に計算を停止する設計です。ただし入力されていない特例をソフトが自動で推測することはできません。**計算結果は税額・控除額の保証ではなく寄附限度額の試算です。** 寄附する前に入力資料と計算根拠を確認してください。

## Windows/Officeのセキュリティ

ZIPは公式リリースURLから取得し、下記SHA-256と照合してください。Microsoft Officeの保護ビューやマクロ警告を一律に無効化しないでください。所属組織のポリシーがマクロ操作を禁止する場合は設定を回避せず利用を停止してください。Excelの信頼済みファイル設定は各組織の手順に従ってください。
