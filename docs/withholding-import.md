# 源泉徴収票のローカル読取（v4.18.2検証版）

Windows配布ZIPに `FurusatoDocumentReader.exe` を同梱し、
Excelの「源泉票を取込」から呼び出します。利用者にPythonの導入は求めません。

埋込テキストPDFはG04等の記号と座標で読み取り、画像OCRと混同しません。
添付のように住宅借入金等特別控除可能額（G36）はあり、
所得税での適用額（G29）が空欄なら、差額からゼロを推定しません。
REQUIRES_REVIEWでも金額を**仮転記**でき、元のブックはバックアップします。
自動計算された寄附限度額は原票照合完了まで表示されません。
「読取内容の確認」で源泉徴収票の参考値との一致を確認する方式です。
画像OCRは日本語Tesseract辞書等の同梱が未完成であり、引き続き検証版です。

源泉徴収票の氏名・住所・個人番号はGitHub・CIへ送信しません。
通知書が届く前に限度額を算定するため、住民税通知書の入力は求めません。
公的年金・事業所得・雑所得は所得年の収入・経費から算定します。

控除可能額G36が存在するのにG29が空欄の場合、G05-G06が非正で源泉税G08が0のときだけ、G29の所得税適用額を0と安全推定します。課税所得が正のケースは従来どおり確認対象です。G05/G06/G27/G28をPDFから取得できた場合は、それぞれの原票値を計算に優先利用します。読取のたびに元データはバックアップします。

## 令和8年分の特定親族照合（v4.18.2）

- 源泉徴収票の `G72` は「特定親族の数」、`G73` は「16歳未満の扶養親族の数」、`G74` は「特定親族特別控除の額」。従来の G72→年少扶養という誤対応を修正しました。
- G72 または G74 が存在する書類は、必ず仮取込 `REQUIRES_REVIEW` とします。G72/G74 は「追加所得」画面の読取専用 B38/B39 に保持し、年少扶養 G73 のみ「操作画面」D23 に取り込みます。
- 確認には「操作画面」の D14～D16 に特定親族の合計所得を人数分入力します。所得年別の法定控除額を再計算して G74 と照合し、人数または控除額が一致しないと確認済みにできません。
- 2025年分の特定親族所得要件は58万円超、2026年分は62万円超。令和8年分の法改正は同年12月1日施行を前提にしているため、施行前の準確定申告は正式対象外です。
- 国税庁 No.1177： https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1177.htm

氏名・住所・個人番号・現物PDFをGitHubやCIへ登録しない方針は変えていません。今回の試験は匿名の項目座標・数値のみです。
