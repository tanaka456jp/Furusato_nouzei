# v4.18.23 — 2022年入居住宅ローン控除：確認済区分のみ5%/7%を適用

## 対象と安全仕様

- 2022年入居の住民税住宅ローン控除は、通常の5%（上限97,500円）と
  一定の経過措置7%（上限136,500円）の両方があり得る。
- 操作画面D35に「未確認」「通常5%確認」「経過措置7%確認」を追加。
  **未確認ならSAFE-TAX-028として寄附目安と住宅控除見込額の表示を停止**。
  単なる入居年から適用区分を推測しない。
- 2022年以外の入居年に過去の「確認」値が残る場合、
  **SAFE-TAX-029** で結果を止める。VBAの新規案件・PDF取込は
  共通ResetSeparateInputsで「未確認」に戻す。
- 2025・2026年分の通常住宅控除の所得税基礎控除差額加算は維持。
  2026年入居は基礎控除差額を加算しない。
- 5%/7%の選択は申告書・住宅取得条件・契約日等を照合した場合のみ。
  住宅取得のすべての特殊ケースを自動判定するものではない。
- 正式配布版およびmain、GAS PR #2、HousingERPは変更しない。

## 自動受入

合成データによる実Excelで、2022年未確認時B38非表示、
確認済5%の住宅控除額44,500円、経過措置7%の控除額62,300円、
2024年入居に旧7%区分が残る場合のSAFE-TAX-029と復帰、
新規入力リセット仕様を確認。既存CIの全機能・VBAUpdater実書戻し・
Excel/GAS41件照合も維持。CI完了まではPASSとは扱わない。
