# v4.18.24 — 電子PDFの実レイアウト監査

正式リリース判定：HOLD。Draft PR #5の隔離実Excel検証だけを対象とする。

これまでの検証はPDFの先頭が%PDF-であることと、Excel内部のA80セルに所得年・バージョンが記録されていることを確認していた。
今回、**実際にExcelが生成した電子PDF**のページ数（通常1、非表示状態から1、分離税額控除付き2）、
A4縦向き、テキスト領域、2ページ目の所得年・住民税・税制版・当該レビュー版を確認する。
さらに全ページのPNG画像を作成しGitHub Actions Artifactに保存する。

取り扱うのはCIで生成した合成データのみ。実際の顧客資料・既存Excelファイル・GAS本番環境は対象外。
失敗すると後続のVBAUpdater試験を停止し、正式配布判定はHOLDとする。

**RICOH等の物理プリンタ、実デスクトップ画面での1920×1080 100/125%および1366×768 150%、
GAS実Google配信の確認は別途必要**。PDF画像をそれらの代用としない。
