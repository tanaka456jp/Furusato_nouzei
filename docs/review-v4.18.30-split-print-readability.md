# v4.18.30 — 申告分離課税の印刷改行・余白修復

## 発見経路

v4.18.29のPC①実Excel・A4 PDFの全検査は4/4 SUCCESS。
しかし合成PDFのPNGを人間が見ると、1ページ目の
「1,000,000／850,000」の控除配分額が**2行に分断**され、
行見出しの表示位置と紛らわしい。2ページ目の税額控除
入力値の控えでも、列Bの金額と列Cの項目名が非常に近い。

## 修正

- 1ページ目の4列見出し行57を43ポイントに拡張し、
  折り返す見出しを中央揃え・太字にする。
- B58:B64の控除配分は「折り返し禁止＋縮小表示＋右揃え」で
  1行を維持。C/D列とラベルの間に字下げを追加。
- 1ページ目の表・注意事項の行高を適正化し、文字が下の行へ
  はみ出しにくいレイアウトへ改善。
- 2ページ目の印刷専用照合欄で、B/Dの入力値とCの項目名との
  視覚的な区切りを追加。
- PC①の実Excelから生成したPDFの本文を行別に抽出し、
  「1,000,000／850,000」が**同一印刷行**にあることを
  必須検査に追加。A4、全5ページ、文字衝突・見出し・税制版、
  入力値の照合チェックも引き続き実施。

所得税・住民税・限度額の計算数式は変更しない。
実顧客書類、既存正式版、main、本番GASは操作しない。
物理紙面の実測・表示倍率別実画面などは正式リリースHOLDのまま。
