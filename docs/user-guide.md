# ふるさと納税 寄附限度額試算 v4.18.2 正式版（対応範囲限定）


## 開発PR #5：特定扶養親族・特定親族特別控除の個別入力（正式配布HOLD）

- 操作画面3行目のリンクから「特定親族明細」へ移動。**合計5人分**について、所得年末の年齢、各人の合計所得金額、適用要件の確認状態を入力する。1～3人目の所得は従来の操作画面D14:D16を参照し、**4～5人目の所得は明細C7:C8へ個別入力**する。二重に入力しないこと。
- 適用要件「要件確認済」は、**19歳以上23歳未満・生計同一・専従者ではない・他の納税者との重複適用がない**等を原票・証憑で確認した場合だけ選ぶ。未確認や年齢欄の欠落・年齢範囲外はHOLDとなり、寄附限度額を表示しない。該当しない人は「対象外」を選択する。
- 2025年分は合計所得58万円以下、2026年分は62万円以下を特定扶養親族（所得税63万円・住民税45万円）として区分。これを超える所得123万円以下は、個人別の特定親族特別控除の法定段階表を**所得税と住民税で別々に適用**。同じ年齢の人でも所得が異なれば控除額は異なる。
- 既存の1～3人目の控除と新しい4～5人目の控除を重複加算せず、国税用・住民税用の計算エンジンへそれぞれ接続する。源泉徴収票のG72人数・G74控除額は**特定親族特別控除だけ**の照合対象であり、通常の特定扶養控除人数とは区別する。G72が5人を超える資料は安全停止する。
- 新規案件開始・源泉徴収票の再取込時には、以前の親族の入力・確認状態をすべて初期化する。控除確認後の各人の年齢・所得・適用状態の変更は旧確認を失効させる。
- 扶養親族の居住要件・重複適用等の法的証明は自動認識できない。実務では親族別に内容を確認すること。Web版の扶養控除自動計算は引き続き未対応。
- 法令確認：[国税庁 No.1177](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1177.htm)、[国税庁 No.1180](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1180.htm)、[葛飾区：令和8年度住民税特定親族特別控除](https://www.city.katsushika.lg.jp/kurashi/1000047/1001463/1026916/1001484/1040330.html)。

## 開発PR #5：所得控除合計の再計算と手入力上書き（正式配布HOLD）

- 操作画面 **B31** は社会保険料・生命保険料・地震保険料・配偶者／扶養等の承認済み控除計算による自動算定額。本人の追加所得が控除適用条件に影響する場合は、対応済み計算式に従い再計算する。
- **B14** は税額計算に実際に使用する所得控除合計額。**D25** が空欄なら B31 の自動算定額を使用し、D25 に金額を入力するとその手入力額を使用する。
- 手入力中は **D26 に「⚠ 手入力上書き中」**、27行目に「社会保険料・扶養・本人所得等の変更へ自動追随しない」旨を表示。該当欄を強調し、計算根拠の印刷にも原票額・自動算定額・使用額・状態を出す。解除は D25 の値を消去する。
- 源泉徴収票の所得控除合計額は **D31** に照合用として表示し、変更後の計算額として流用しない。原票との差額が残る場合は確認前の限度額をHOLDし、「読取内容の確認」で明細を確認する。
- **確認済み状態は入力内容と連動する。** 明細を確認した時点の各入力値・本人の追加所得・配偶者／特定親族所得・上書き額・税制年・原票参照額を内部照合用に保持する。後から条件や金額を変更すると旧確認は無効となり、限度額はHOLDする。元の内容に戻した場合を除き、再度「読取内容の確認」が必要。新規入力・源泉票再取込時は確認記録をクリアする。
- 配偶者（特別）控除、特定親族特別控除、住民税の人的控除差など未確認の法定要件は、入力だけで正当性が保証されるわけではない。独立した税額検算とWindows実機受入が済むまで正式版へ反映しない。

本パッケージはv4.18.2正式版です。ただし寄附限度額の**試算**を目的としており、2025年・2026年分以外の税制、自治体独自の課税、申告上の特殊な控除等は未対応です。正式版という名称は全税務ケースの計算結果を保証するものではありません。初めて利用する前に合成ケースで動作確認し、実案件では計算根拠と原票を照合してください。
本体はv4.18.2、税制マスタの承認版は2026-11-05-bundledです。
**本体バージョンと法令マスタの承認版は別の管理番号**です。
法令カタログの承認状況を本体リリースに合わせて書き換えることはありません。

## 申告分離課税（v4.18.15 検証版）

操作画面上部の「詳細設定・申告分離課税へ」をクリックし、案件区分「申告分離」と所得年を設定します。分離所得は所得控除前・経費差引後で入力し、該当なしは0です。源泉分離、申告不要選択、NISAは入力しません。所得税・住民税それぞれの控除合計（基礎控除を含み、検算対象の寄附金控除を除く）、法定人的控除差、検算する寄附額を入力します。自治体の標準税率（市町村6%・4%／指定都市8%・2%）を確認して選択します。超過課税等は「条例差・不明」を選択します。照合条件を読み、適用が確認できた場合は「照合済」を選択します。

55行目が計算状態、56行目が自己負担2,000円以内の千円単位の寄附目安と入力寄附の自己負担、58行目以降が配分・税額です。69行目に1円単位の最大額と千円未満切捨て額が表示されます。「計算根拠」から詳細結果に移動できます。詳細結果だけの印刷とPDF保存は、Excelのマクロ一覧から PrintDetails または ExportDetails を実行します。通常の自動計算またはF9で更新します。SAFE-TAX-016では旧B24/B36を使った試算を保留し、詳細設定への移行を案内します。確定申告をする案件ではワンストップ特例を選択できません。

詳細設定の値は案件保存に含まれます。「新規入力」の確認後と、源泉徴収票取込の確認・バックアップ完了後に詳細設定を初期化します。通常の給与試算を再開するには「給与・通常」を選びます。

この検証版は標準税率の市町村・指定都市、通常税率、合計所得100万〜2,350万円を対象とします。源泉徴収精算、条例差、損失・特例、未対応の税額控除、退職・山林は個別照合です。詳細設定の計算は正式リリースHOLDです。

72～77行目で、通常0.7％の住宅ローン控除、対象国内普通配当、所得税枠内の外国税額控除を入力できます。適用しない項目は0です。81～86行目で寄附前後の所得税、復興特別所得税、税額控除の内訳を確認できます。適用条件と停止理由は税制監査資料を参照してください。

## v4.18.2 正式配布時の制約と安全確認

- 配布ファイルにはコード署名を付けていません。WindowsやOfficeの警告は発生し得ます。**安全性を確認せずマクロ警告を一括無効化したり、Officeの保護ビュー設定を全面解除したりしないでください。**
- 実Excel受入、ブック保存・再起動、VBAUpdaterの隔離書戻し、PDFの生成について自動テストに合格したソースを対象としています。テストは**合成データ**が中心です。実顧客の源泉徴収票と住民税決定通知書の独立した全件突合、および全解像度の有人画面評価は含みません。

- 住宅ローン控除、分離課税、公的年金等は説明した条件でのみ対応します。適用条件の不明点、個別税制の特例等は結果をHOLDとして扱い、寄附限度額を確定的に案内しないでください。
- 寄附の自己負担額は自治体で確定する所得税・住民税額により変わります。試算表示額を寄附額の保証としないでください。
- 2027年分以降の税制は未承認です。2026年分は令和8年12月1日施行後の通常の年末調整等を前提とし、それ以前の準確定申告等に適用するものではありません。
- 環境：Windows 11 / Excel 365を想定。外部EXEへのアクセス可否やVBAへのアクセス許可は所属組織のポリシーを優先し、禁止設定を回避しないでください。
- 公開パッケージは署名なしです。配布先が真正性を確認できるよう、GitHub ReleasesにSHA-256一覧と受入テスト結果の説明を併載します。


## 一括取込の両方式表示と手修正・再計算（内部評価）

一括計算一覧の **I列「ワンストップ上限（仮）」** と **T列「確定申告上限（仮）」** は別々の試算です。途中のL〜S列は同じ人の数値根拠として非表示になっています。片方が条件不足の場合はもう片方をコピーせず、該当する金額を空欄にします。いずれも給与所得のみなどの仮定を置いた参考額であり、確定申告をするとワンストップ申請は無効になります。

一括一覧の「個別数値の手修正」から「一括入力修正」シートを開き、**氏名・原票ページと同じ行**の給与・社会保険・生命保険料・配偶者・住宅ローン情報などの黄色い入力欄を訂正します。所得控除合計額は入力欄にありません。**「修正値で全員再計算」ボタンを押すと、試算対象年の法令に基づく所得控除合計を自動的に組み直し、両方式の限度額と判定を更新**します。原票年・試算年・自治体区分も必ず照合してください。詳細入力の各行は原票ページ番号で他人と分離されます。ページ番号・隠し資料種別・注意コードは変更しないでください。

再計算は同梱のローカル `FurusatoDocumentReader.exe` を使用します。読取EXEがない、入力形式が不正、または更新結果が検証できない場合は、既存一覧を変更しません。所得控除合計は自動算出欄なので直接編集できません。給与・控除・税額が整合しない行は **HOLD** として両方式の金額を空欄にします。

一括入力修正の **AD～AG列** に、一般扶養・特定扶養・老人扶養（同居老親等以外）・同居老親等の該当人数を入力できます。各区分の所得税・住民税控除額と人的控除差は別々に再計算します。**AH列** は、2026年の新生命保険料控除に係る23歳未満の扶養親族該当性（1=確認済で該当／0=確認済で非該当／空欄=未確認）です。一般扶養には16～18歳と23歳以上が混在するため、年齢を推測しません。16歳未満・特定扶養人数から23歳未満が確定する場合と入力が矛盾したとき、また必要な確認がないときはHOLDとします。前年の原票人数を翌年に引き継ぐ場合は、年齢・所得要件と居住・生計条件を個別に確認してください。特定親族特別控除（通常の特定扶養とは別区分）など未対応項目は安全上引き続きHOLDです。再計算前に手入力した内容が自動的に確定額になるわけではありません。

なお、ふるさと納税の寄附先5自治体以内等の条件、住宅ローン控除初年度の申告義務、配偶者・扶養の所得や年齢、自治体独自の条例などは別途確認が必要です。一括入力・計算結果には個人情報が残るため、**他の人へブックを共有する前に一括一覧を消去**してください。原本のPDFや個人情報はGitHub Actionsには送らず、テストは合成データのみで実施しています。

## 複数人一括計算（v4.18.36候補・正式公開前）

操作画面の「複数人一覧」から5人分など複数ページのPDFを読み込むと、
「一括計算一覧」シートに **1ページ＝1人** の順で支払金額・給与所得・所得控除・源泉徴収税額・社会保険料・参考限度額・判定理由を表示します。

**一括計算は給与所得だけの参考試算**です。他の所得・申告分離課税など複雑な条件は対象外です。住宅ローン控除は源泉徴収票の条件が再構成できた範囲のみ試算します。原票から条件を確認できない行はHOLDとし、限度額を空欄にします。精緻な控除計算・個別の申告条件の確認は単独計算画面だけで実行してください。

一括一覧のデータが残っている間は、複数人の給与情報を混入させないため「案件保存」を拒否します。必要な内容は適切に別途記録した後、一覧の「一覧消去」を実行してください。「新規入力」でも、明示確認後に一覧を消去します。**Excel本体を通常の上書き保存（Ctrl+S）した場合は同じブック内に一覧が残るため、他者に共有する前に必ず一覧を消去してください。**

## 前年の源泉徴収票から翌年分を試算する場合（検証版）

操作画面B4で計算対象年を選び、源泉徴収票を取り込みます。例えば令和7年分の源泉票を令和8年の試算に利用すると、原票の年分はB11、試算対象年はB4に独立表示されます。前年票に記載された給与所得控除後の額・所得控除合計・源泉徴収税額を、翌年の確定値としてそのまま使用しません。

給与・社会保険料・年間保険料・扶養親族などを令和8年分の見込条件に更新したあと、**操作画面D33（住宅ローン控除欄右側）「翌年試算の前提確認」** で「確認済」を選び、「読取内容の確認」を実行します。対象年に住宅ローン控除がないことを確認した場合は「住宅控除なし」を選べますが、B33/B34の当年控除欄を両方空欄にしてください。源泉票と試算対象年の組合せはD34に表示します。

前年の住宅ローン控除は翌年へ自動流用せず、入力変更時には前回の確認を失効させます。前年票の再取込時は、前年の年金・事業・雑所得や分離課税所得を誤って翌年へ持ち込まないよう追加所得欄を初期化するため、当年の見込額を再入力してください。翌年試算は正式な寄附限度額を保証するものではありません。
