# ふるさと納税 寄附限度額試算 v4 検証用

このパッケージは受入検証用です。顧客案件への使用は正式受入後としてください。

1. ZIPをフォルダにすべて展開します。専用のWindows Excel検証環境で START_SETUP.cmd を実行します。
2. セットアップが成功したら Furusato_nouzei.xlsm を開きます。失敗時は setup_launcher.log と setup.log を確認します。上書きは行いません。
3. メイン画面で所得年を選び「税制を更新」を押します。源泉徴収票の所得年も入力します。
4. 水色の欄に源泉徴収票を転記します。必須金額で記載がなければ0とし、配偶者や特定親族が該当する場合は合計所得が0円でも0と入力します。ワンストップ特例を選ぶ場合は、利用要件を満たすことを確認してから「確認済」を選びます。
5. 金額と状態を確認します。「計算根拠」から内訳・印刷プレビュー・PDF出力を利用できます。「印刷プレビュー」からExcelの印刷画面で内容を確認して印刷します（押しただけでは印刷しません）。PDFの同名ファイルは上書きせず、失敗時に不完全なPDFを残さない構成です。
6. 「案件保存」で案件のコピーを保存します。再編集は、そのファイルをExcelで開きます。新しい案件は「新規入力」で開始できます。税制更新前のコピーは同じフォルダ内の Furusato_backups に作られます。
