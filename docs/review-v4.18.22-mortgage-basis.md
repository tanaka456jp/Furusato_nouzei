# Excel v4.18.22 — 住宅ローン控除住民税上限の所得税基礎控除差額補正

正式配布判定: HOLD / Draft PR #5 のみ。

## 検出した欠陥と修正

2025年分以降の所得に対応する住民税（2026年度以降）で、
2022～2025年入居の通常5%枠の住宅ローン控除上限を計算する際、
所得税の課税総所得金額等に **MAX(0, 当年の所得税基礎控除額－480,000円)**
を加える必要がある。従来の通常画面 B38 はこの加算がなかった。

また、従来の B13－B14 は給与所得と所得控除だけで、
普通に申告する公的年金・事業所得・雑所得を欠落させる。
新方式では既存の国税課税総所得 J12（千円未満切捨て）を参照し、
モデルの所得税基礎控除 F15 と組み合わせて算定する。

計算対象は所得年2025・2026の標準5%/97,500円枠に限定し、
2026年入居の場合は居住年区分に従い基礎控除差を加算しない。
ただし2022年入居は契約時期による7%/136,500円経過措置と区別できず、
**SAFE-TAX-028** で個別照合が終わるまで寄附目安を表示しない。
可能額 B34 のマイナス値も不正入力として拒否。

## 独立合成テスト（実Excelで確認するまでPASSではない）

- 給与所得5,200,000円・所得控除5,000,000円、居住開始2024年、
  控除可能額150,000円、所得税適用額0円:
  2025年分・所得税基礎控除630,000円 → 住民税見込17,500円。
- 同じ条件の2026年分・所得税基礎控除670,000円 → 19,500円。
- 2026年分に通常の追加所得500,000円を加える → 44,500円。
- 2026年入居の同条件 → 35,000円。
- 2022年入居 → SAFE-TAX-028、寄附額非表示。負の控除可能額は拒否。
- 全ケースの後で入力状態を戻して正常表示に復帰。
- 既存52・分離税70・Excel/GAS41・VBAUpdaterの全回帰は引き続き必須。
