# v4.18.29 — PDFの計算条件照合欄と可読性改善

正式版への反映はHOLD。Draft PR #5、合成データのみの受入。

## 確認した問題

v4.18.28のPC①実Excel PDFを目視確認したところ、計算根拠で金額の直後から
説明文が始まるため視線が区切りにくく、申告分離課税の税額控除比較2ページ目は
寄附前後の金額だけで**元入力値の照合材料がない**。
メイン操作画面印刷では「追加所得」への案内文末が次の行へ短く折り返す。

## 改善点

- 計算根拠の金額の右の説明文に1文字分の字下げを追加。
- 操作画面の長い案内を短くし、行高さを42→30ポイントに調整。
- 申告分離課税の税額控除比較2ページ目に印刷専用
  「計算条件の照合（入力値の控え）」を追加。
  住宅入居年、適用上限反映済残高、住宅控除可能額、普通配当対象額、
  適格外国所得税額、調整国外所得金額、適用条件の確認状態、
  課税自治体を**数式で元セル参照**して再掲。
- B55が「計算可能」でないときは印刷専用の控えも空欄。
  閲覧用セルはロックし、入力内容を変更する経路にはしない。
- VBA PDFの印刷範囲を2ページ目A80:D93に広げる。
  PC①実ExcelでPDFのA4・2ページ・可視照合ラベルを検証する。
- ソース値と印刷元を静的テストで照合する。既存の52基準ケース、
  70分離課税ケース、41 Excel/GAS合成ケース、VBAUpdater受入を維持。

実案件税額と自治体通知書の独立突合、GAS実Googleの独立再受入。
