# v4.18.27 — 2022年入居住宅ローン控除：適用要件の表示と上限境界

## 安全な入力ガイド

2022年入居の住民税住宅ローン控除には一般5%（上限97,500円）と、
消費税10%で一定の契約時期等に該当する経過措置7%（上限136,500円）がある。
源泉徴収票には契約日・住宅区分等が必ずしもないため、入居年だけで
7%を自動認定してはならない。

この版ではD35「2022年入居の特例区分」にExcel入力メッセージを追加。
経過措置7%の確認が必要な代表的条件を表示する。

- 消費税率10%の住宅取得
- 新築：2020年10月〜2021年9月の契約
- 建売・中古住宅・増改築：2020年12月〜2021年11月の契約
- 条件が不明なら必ず「未確認」（SAFE-TAX-028で目安非表示）

契約時期だけで法令要件を満たしたと自動認定するわけではない。

## 実Excel数値境界

PC①の隔離合成試験で、追加所得4,500,000円、住宅ローン控除可能額
1,000,000円、所得税適用額0円をセットし、十分な課税総所得基礎を確認。

- 2022年7%経過措置を確認済 → 住民税移行上限136,500円
- 2022年通常5%を確認済 → 上限97,500円
- 所得税適用額=控除可能額 → 住民税移行残余0円
- 未確認へ戻す → SAFE-TAX-028再発動、住宅控除見込額空欄
