# v4.18.32：PDF印字欄の位置照合を追加（検証版）

## 背景
v4.18.31は、PC①実Excelから出力された申告分離課税A4・2ページの
計算条件8項目について、元のExcel入力とPDFテキストの一致を検証した。
ただしPDF内で金額や特に「0」が複数回印刷されている場合、
異なる欄の数値でも存在検査を満たす可能性があった。

## 改善
- PDF2ページ目の「計算条件の照合（入力値の控え）」を基準に、4行×2組の
  項目名と値をPDFの文字座標で検証。
- 左項目名はA列・値はB列、右項目名はC列・値はD列にあり、
  各値がその項目名と同じ印刷行にあることを必須とする。
- 8項目すべてについて印字値、行配置、左右の列配置、順序と
  Excel実機が記録したSHA-256の一致を継続確認。
- 数値を別の行へ動かす、値を別の列へ移す、元の表示値を変える、
  証跡を改変する等の模擬異常を拒否する自己テストを追加。
- GitHub-hosted staticジョブでこの自己テストを毎回実行する。
  PC①での実PDF監査も必須のまま維持。
- 表示版とインストーラー版をv4.18.32に統一。

## 判定上の限界
PDF上の文字位置までを自動検査するが、物理印刷による文字欠けや色の視認性、
複合的な実税務条件の適否、画面倍率による操作性はこの監査の対象外。
正式リリースはHOLD。main、本番GAS、既存正式版は変更しない。
