# v4.18.31 — 実Excel入力8項目とPDF印字の照合強化（検証版）

## 発端と修正
v4.18.30 のPC①実Excelは、A4・2ページの分離課税帳票で金額を一行に収め、
文字の重なりや項目名の存在を確認した。ただし、画面の入力値と印字された値を
一対一で検証する仕組みは不足していた。

v4.18.31 では税制・計算式を変更せず、次の検証を追加する。

1. `tools/test_separate_excel.ps1` は実Excelで出力直前に、住宅の入居年・上限反映済残高・
   控除可能額・普通配当・外国税額・国外所得・適用条件・自治体の8項目が
   それぞれ元の入力値と一致することを確認する（従来からのチェックを維持）。
2. 実Excelから作られた **同じPDFのSHA-256** と8項目の検証値を、
   `split-result.print-inputs.json` に書く。データはCI用の合成税務データのみ。
   氏名・住所・受給者番号等をJSONへ書かない。
3. `tools/verify_excel.ps1` はこの証跡をPDFと一緒にArtifactに含める。
4. `tools/audit_pdf_layout.py` はハッシュが一致すること、JSONのスキーマが
   **8項目ちょうど**であること、年度・版表示、各項目名とその印字値が
   PDFの2ページ目に抽出できることを確認する。
   ファイルの欠落・改ざん・表示値の欠落はFAIL/HOLDとする。
5. A4・ページ数・衝突・「1,000,000／850,000」の1行表示・PNG証跡を従来どおり検査する。

## 受入区分
- この検証は **PDF電子帳票上の文字列の存在検証** であり、税法的正しさ・
  配置の完全性・紙面プリンタでの印字品質は証明しない。
- 行内で数値0がほかにも印字されているケースでは、同じ0の存在検査だけでは
  個々の欄の描画を証明できない。欄位置の目視確認は継続する。
- 他の表示倍率、顧客資料を使用した独立照合、GASの実環境受入、
  完全な物理印刷検査は未完了。正式リリースはHOLDを維持する。
- GitHubのmain、既存正式配布物、本番GAS、実顧客データは変更しない。
